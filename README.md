# AwemeLiquidBar 1.0.46b

Changes from 1.0.46a:

- Top category group can show 1, 2, 3 or 4 items (default 3).
- One-item mode hides the selected pill and uses text emphasis only.
- Category titles use the resolved bar style and safer sizing.
- Selected pill movement uses a dedicated spring animation.
- The bottom-bar visibility mask now covers the complete resident floating-bar controller, not only UITabBar.
- The right search button remains available when the top menu/category glass switch is off.

The GitHub workflow builds and uploads `AwemeLiquidBar-1.0.46b-Xcode27-rootless`.
