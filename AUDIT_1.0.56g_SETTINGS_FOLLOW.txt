AwemeLiquidBar 1.0.56g focused Settings-drawer fix

Scope: ONLY Settings drawer/native-tab-bar horizontal following.

Regression removed from 1.0.56f:
- no left-edge clipping mask on AWEAlbumMorphController.view;
- no direct write to controller.view.transform from Tweak.x.

New invariant:
- Swift owns the controller transform as translationX(horizontalRouteOffset)
  + translationY(userVerticalOffset), so route following cannot erase the
  user's configured vertical offset/height position.
- Tweak.x mirrors the live AWENormalModeTabBar minX only when that native bar
  is partially exposed by a non-interactive side drawer.
- Because Settings shifts the native bar LEFT, the replacement also shifts
  LEFT, naturally exposing its RIGHT-hand slice in the left page strip.
- During an interactive navigation transition horizontalRouteOffset is forced
  to 0. The existing percentComplete return mask remains authoritative and is
  otherwise untouched.

No changes to:
- messages-root visibility fix;
- chat interactive return fraction code;
- fullscreen geometry;
- clean-screen/status-bar code;
- profile image/video progress fixes;
- user vertical offset setting semantics.
